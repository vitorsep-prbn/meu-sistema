# 💻 Meu Sistema

Sistema de console em **C#** para gerenciamento e autenticação de usuários.

## 🛠️ Funcionalidades

- [x] **Cadastro:** Registrar novos usuários.
- [ ] **Listagem:** Listar todos os usuários.
- [ ] **Busca:** Pesquisar usuários.
- [ ] **Remoção:** Excluir usuários.
- [ ] **Autenticação:** Login com usuário e senha.

## 🚀 Como Executar

### Pré-requisitos
* SDK do **.NET** instalado.

### Comando
```bash
dotnet run
```
