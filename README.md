# 💻 Sistema de Console em C#

![C#](https://shields.io)
![.NET](https://shields.io)
![Status](https://shields.io)

> Sistema robusto de terminal desenvolvido em C# focado no controle, gerenciamento e autenticação de usuários.

---

## 🚀 Funcionalidades

Confira abaixo o que o sistema já faz e o que está planejado para as próximas atualizações:

| Status | Funcionalidade | Descrição |
| :---: | :--- | :--- |
| ✅ | **Cadastrar usuários** | Criação de novas contas com validação de dados. |
| ✅ | **Listar usuários** | Exibição em lista de todos os perfis registrados. |
| 🔄 | **Buscar usuários** | Localização rápida de cadastros específicos. |
| 🔄 | **Remover usuários** | Exclusão de contas do banco de dados. |
| 🔐 | **Login Seguro** | Autenticação através de usuário e senha. |

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** C#
* **Plataforma:** .NET Core / Console Application
* **Paradigma:** Orientação a Objetos (POO)

---

## 🏃 Como Executar o Projeto

Para rodar este sistema localmente em sua máquina, certifique-se de ter o [.NET SDK](https://microsoft.com) instalado e execute o comando abaixo no terminal:

```bash
dotnet run
```
